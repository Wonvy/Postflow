# 朗读

[English](read-aloud.md)

点文章标题下面日期旁边的「朗读」。念的是阅读区里现在显示的内容（开着全文念全文，开着翻译念译文），正在念的那一句会标出来；
打开别的文章也接着念，列表底下有一条小控制条。按钮会变成一条控制条，可以暂停、跳到上一句或下一句、调语速。
念完会接着念列表里的下一篇，见[听新闻](#听新闻)。

## 听新闻

点列表顶上的**耳机**按钮（听这个列表），Postflow 就从打开的那篇（没打开的话从第一篇）开始，一篇接一篇往下念；
点文章标题下面的「朗读」也一样，从那篇开始。每篇开头先报来源和标题。阅读区开着的正是刚念完的那篇时，会跟着打开下一篇；
否则在后台接着念，列表底下有控制条。

在「设置 → 朗读 → 听新闻」里，或者控制条上的选项按钮里选：

- **每篇念什么**：全文、**摘要**（订阅源自带的简介，没有的念开头几句）、**AI 总结**，或者**只念标题**。
- **念完自动念下一篇**（默认开）：按开始念时那个列表的顺序往下念，播客和视频跳过。
- **念完标为已读**（默认开）。跳过的不标。
- **定时停止**：15、30、45、60 分钟后，或者念完这一篇停。

控制条上有「下一篇」按钮；用本机声音念的时候，键盘和耳机上的播放 / 暂停键、下一首键也能用。

### AI 总结和花费

AI 总结和 AI 面板里的总结是同一份，存在这台设备上，已经写过的不再花钱。Postflow 只让 AI 写正在念的这一篇和下一篇
（提前准备好，换篇时不用等），不会把整个列表都送去总结。选项菜单里显示这次让 AI 写了几篇。AI 用不了的时候（没设置服务、
余额不足、没网），只提示一次原因，这次后面都改念订阅源的摘要，不会反复重试。邮件只有在「设置 → AI」里允许了才会发给云端 AI，
否则那封念它自己的摘要。

## 声音

在「设置 → 朗读」里选：

- **本机声音**：由开源的 [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) 模型在你自己的电脑上合成，
  运行库是 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)（和播客字幕是同一个）。文字不会发到网上。
  比多数系统语音自然得多，macOS、Windows、Linux 上都一样。
- **系统语音**：操作系统自带的声音。不用下载，好不好听看系统；多数 Linux 桌面没有。

默认是「自动」：下载了本机声音就用它，没有就用系统语音。每种语言有一个声音菜单和试听按钮，换一种声音会自动念一句给你听。

本机声音能念中文和英文。日文、韩文等其他语言的文章用系统语音念。

## 声音模型

模型不随安装包带，在「设置 → 朗读」里下载：

| 模型 | 大小 | 声音 | 适合 |
| --- | --- | --- | --- |
| Kokoro v1.1-zh | 370 MB | 55 种女声、45 种男声（中文），另有 3 种英文 | 中文 |
| Kokoro v1.0 | 345 MB | 28 种美式、英式英文声音，另有 8 种中文 | 英文 |
| ZipVoice | 183 MB | 你添加的录音的声音（见下面） | 最像真人 |

两个都装了的话，「自动」用 v1.1-zh 念中文、用 v1.0 念英文。每个文件下载后都核对 SHA-256；Hugging Face 慢或者连不上时，
从魔搭上的副本下载。都下载不动的话，可以自己把文件下载到一个文件夹，再点「从文件夹导入」。模型列表来自
[`public/catalog/voices.json`](../public/catalog/voices.json)，应用每天联网看一次，加新模型不用发新版本。

中文默认的声音（女声 94）是在全部 100 种中文声音里，用语音识别听几段新闻、听得最准的一个。这只说明咬字清楚，
不代表最好听，可以在声音菜单里多试几个。

## 用你自己的声音（ZipVoice）

[ZipVoice](https://github.com/k2-fsa/ZipVoice) 没有自带的声音，它照着你在「声音样本」里添加的一段录音念，
音色和语气都学那段录音，所以最像真人。

1. 在「设置 → 朗读」里下载 ZipVoice。
2. 点「添加录音…」，选一个音频文件（MP3、M4A、WAV、Ogg、FLAC……）。最好是 3–10 秒、一个人清楚地说话，
   没有音乐和杂音。Postflow 只留开头 12 秒，并去掉前后的静音。
3. 检查录音下面的文字：要和录音里说的一字不差。装了语音识别模型（设置 → 字幕）会自动识别出来，否则自己填。
4. 在页面上面给中文、英文分别选一段录音。用同语言的录音效果最好：中文录音念英文会带口音，有的词念不清。

只用你自己的声音，或者得到本人同意的录音。录音只存在这台电脑上，不同步。

ZipVoice 比 Kokoro 慢（Apple M4 上大约是实时的 1.5 倍，Kokoro 是 4 倍），较老的电脑上可能跟不上，句子之间会停顿。
它的词典里没有英文词，所以 Postflow 同时下载 Kokoro 的英文词典，第一次加载时换成标准国际音标。这个版本的
sherpa-onnx 里 ZipVoice 不用中文数字规则，所以中文句子里的数字由 Postflow 自己写成汉字。很短的句子没法念快，
按正常语速念好以后再放快。

## 怎么念的

阅读区把正文切成一句一句，每句交给核心合成，拿回声音来放。放这一句的时候，后面两句已经在准备了，所以句子之间不用等。
在 Apple M4 上，合成一句的时间大约是念完它的四分之一；第一句要多等一两秒，因为那时才加载模型。调语速会从当前这一句重新合成。

念的时候模型约占 700 MB 内存，十分钟不用就会释放。

在别的设备上用浏览器打开 Postflow（设置 → 网页访问）时，是运行 Postflow 的那台电脑念好、浏览器来放，所以手机上也是同样的声音。

## 念之前的整理

Kokoro 按词典念词，词典里没有的词直接跳过，而新闻里偏偏全是缩写和品牌名。Postflow 先把每句话整理一遍：

- 网址不念。
- 缩写逐个字母念（`GPU` → G P U），连写的名字拆开（`OpenAI` → Open AI，`MacBook` → Mac Book），
  其余不认识的词尽量拼成词典里的几个词（`Tencent` → ten cent）。
- 英文句子里的数字、年份、序数、百分比、金额、时间、日期都写成英文单词
  （「$3.2 billion in 2026」→「three point two billion dollars in twenty twenty-six」）。
- 中文句子里的 `5.2%`、`1,234`、`10:30` 先改写一下，让模型自带的中文数字规则念对。

拼不出来的名字（比如用拼音写的 Huawei 等很多中文名字）还是会被跳过。

## 在命令行里试

```sh
cargo run --release -p postflow-speech --example speak -- models .postflow-dev/local/voices
cargo run --release -p postflow-speech --example speak -- download .postflow-dev/local/voices kokoro-v1.1-zh
cargo run --release -p postflow-speech --example speak -- prepare .postflow-dev/local/voices kokoro-v1.1-zh "OpenAI 发布了 GPT-5"
cargo run --release -p postflow-speech --example speak -- say .postflow-dev/local/voices kokoro-v1.1-zh zf_094 "你好" out.wav
```

`prepare` 打印出整理后要念的句子，某个词念错时可以用它查原因。
