# 播客字幕

[English](subtitles.md)

播客播放的时候，ShibaPost 可以把正在说的话显示出来。点播放器上的 **字幕** 按钮（阅读区的播放条上，或者列表底下的迷你播放器上），
声音放到哪儿，下面那行字就跟到哪儿。

- 节目自己发布了带时间的文字稿（Podcasting 2.0）的，直接用它。
- 没有的，ShibaPost 在**你自己的电脑上**把这一期转成文字，音频不会上传到任何地方。

## 它是怎么做的

ShibaPost 不去录扬声器里放出来的声音。它把这一期下载到本机（和「下载离线听」是同一份文件），从你正在听的地方往后读这个文件；
不用等整期下完，开头一部分到了就开始识别。识别比播放快几倍到几十倍，所以按下播放几秒钟后第一句就出来了，之后一直走在播放前面；
转到结尾再回头补上你跳过的部分。下载还没到你正在听的地方时，播放条上会说下到哪儿了。
个别要整个下完才读得了的文件，下载完会自动开始转，不用点「重试」。
拖到还没转的地方，就改从那里接着转。

转出来的结果存在这台设备上，下次直接用；它也作为文字稿列在播放条下面，点一句就从那里放。本机转写的文字稿不同步。

同一时间只转一期。换一期听，上一期就停下，已经转的部分留着。

## 字幕样式

在 **设置 → 字幕 → 字幕样式** 里选字幕的样子，每种都有实时的预览；也可以点播放条上字幕按钮旁边的小箭头换。

| 样式 | 效果 |
| --- | --- |
| 逐字高亮（默认） | 说到哪个字，哪个字亮起来 |
| 打字机 | 说一个字出现一个字，后面跟着闪烁的光标 |
| 弹跳入场 | 每个字说到时弹一下 |
| 玻璃面板 | 半透明的背景，下面一条进度线 |
| 双语 | 原文在上，译文在下（会打开自动翻译） |
| 重点强调 | 大字，说过的部分像荧光笔划过 |
| 滚动 | 上一句、下一句也显示，随着说话往上滑 |
| 粒子浮现 | 字从光点里浮出来 |
| 说话人标签 | 用彩色标签标出是谁在说 |
| 波浪背景 | 柔和流动的背景 |
| 极简 | 安静、简洁 |

每个字什么时候说出来来自识别模型：SenseVoice 和 Parakeet 给出每个字（词）的时间；Whisper 和节目自带的文字稿没有，
就在这一句的时长里平均分。系统开了「减少动态效果」时，样式只保留颜色变化，不再动。

字幕本身也能直接调：

- **字号**：鼠标放在字幕上，按住 Ctrl（Mac 上 ⌘，或者在触控板上双指捏合）滚动滚轮。
- **高度**：拖播放条里字幕区域的下沿；双击下沿恢复。
- **语言**：在字幕上点右键，选只看原文、原文和译文、只看译文，以及翻译成什么语言（只管字幕，「设置 → 翻译」不变）。
  同一个菜单里可以把字号、高度恢复默认。

## 区分说话人

打开 **区分说话人** 以后，每个人用一种颜色（所有样式都是）。播放条下面的文字稿分三列：时间、说话人的记号、文字；
换人的时候在第一句上面写上是谁（按第一次开口的先后叫说话人 1、说话人 2……）。节目文字稿里写了名字的，直接用名字。

记号的形状分男女：**方形**是男声，**圆形**是女声，听不出来是小**菱形**。男女是按每个人说话的音高猜的，
识别时在本机顺便量：大多数男声说话在 85–150 Hz 左右，女声在 180–260 Hz 左右，介于两者之间的就是菱形。

本机识别的字幕要分说话人，需要另一个认声音的小模型：**3D-Speaker CAM++**（27 MB，在 设置 → 字幕 的「声纹模型」下面）。
装好以后，每隔几秒钟的话会和这一期里已经听到的声音比一比。它和你选的任何识别模型一起用，只在本机运行。
装它之前转好的单集没有说话人；在它的文字稿里点 **重新转写** 就有了。

## 翻译字幕

打开 **自动翻译字幕**（在 设置 → 字幕 里，或者字幕按钮旁边的菜单里）。节目不是你的语言时，每句下面显示译文。
用的是 **设置 → 翻译** 里的选择：翻译成什么语言，用免费的离线模型（要下载模型时会先问你）还是你的 AI 服务。

选了 **双语** 样式时，节目本来就是你的语言也会有第二行：中文节目给看中文的人译成英文，英文节目译成界面语言。

只翻你正在听的地方附近的句子，往前一分钟左右。译文和字幕一起存在这台设备上，再听一遍、重新打开 ShibaPost 都不用再翻
（用 AI 服务时也不会重复花钱）。

## 语音识别模型

模型不随安装包带。在 **设置 → 字幕** 里下载；可以装好几个，随时换。

| 模型 | 语言 | 下载大小 | 说明 |
| --- | --- | --- | --- |
| SenseVoice Small | 普通话、粤语、英语、日语、韩语 | 229 MB | 中文最准，带标点，速度最快 |
| Whisper Small | 近百种语言 | 358 MB | 英文和大多数其他语言用它 |
| Whisper Base | 近百种语言 | 153 MB | 比 Small 小、快，准确度差一些 |
| Parakeet TDT 0.6B v3 | 英语和另外 24 种欧洲语言 | 640 MB | 准确度高，带标点和大小写；不支持中文 |

这份列表来自仓库里的 [`public/catalog/speech.json`](../public/catalog/speech.json)。ShibaPost 每天联网看一次，所以以后加新模型
不用发新版本，只要随应用带的识别运行库（[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)）已经支持那一类模型。
需要更新运行库的模型会显示「需要新版本的 ShibaPost」。

每个模型由它自己的作者发布，许可各不相同，设置里每个模型旁边都写着。

### 模型从哪儿下载

每个文件都有好几个下载地址：Hugging Face、它的镜像 hf-mirror.com，SenseVoice 和 Whisper 还有国内能直接访问的
[魔搭社区（ModelScope）](https://modelscope.cn)。下载一个模型之前，ShibaPost 会从每个地址各取开头一兆测一下速，
从最快的那里下；连不上的只在最后才试。所以不管你的网络能不能打开 Hugging Face，都不用自己选。
Parakeet 目前只在 Hugging Face 上有。

魔搭上的副本是社区成员上传的，不是 ShibaPost 放的。只有每个文件都和原版一模一样（大小和 SHA-256 都对得上）才收进来，
下载完 ShibaPost 还会再核对一次 SHA-256。

### 下载慢或者失败

下到一半断了会接着下，一个地址下不了会换下一个。还是不行的话，可以自己下载文件，再用 **从文件夹导入**：

1. 打开 `public/catalog/speech.json`，找到那个模型；每个文件都写着文件名和下载地址。在国内用 `modelscope.cn` 开头的地址。
2. 把这几个文件下载到同一个文件夹，文件名不要改。
3. 在 设置 → 字幕 里，点那个模型旁边的「从文件夹导入」，选这个文件夹。

不管文件从哪儿来，ShibaPost 装之前都会核对它的 SHA-256。

### 声纹模型

**3D-Speaker CAM++**（27 MB，Apache-2.0，来自阿里的 [3D-Speaker](https://github.com/modelscope/3D-Speaker)）单独列在
「声纹模型」下面，开着「区分说话人」时显示。它不是识别模型，没有「使用」按钮：装好以后和你选的识别模型一起用。

### 换模型

在装好的模型旁边点 **使用**。之后转写的单集用新的模型。已有的文字稿保留；想重转某一期，打开播放条下面的文字稿，点 **重新转写**。

## 东西放在哪儿

都在 ShibaPost 本机数据目录的 `speech` 文件夹里（设置 → 字幕 里写着路径）：模型，每一期转写结果的一个小 JSON 文件，
以及每一期每种语言的译文各一个文件。
设置 → 存储空间 里能看到它们占了多少，设置 → 字幕 里可以把存下的字幕全部清掉。

## 从浏览器访问 ShibaPost 时

开了网页访问以后，手机或浏览器里看到的是同样的字幕。模型装在运行 ShibaPost 的那台电脑上，活也是它干的。

## 给插件开发者

插件可以在播放时读到字幕、说话人和译文，也可以控制播放器：见 [`api.player` 和 `api.subtitles`](plugins.zh-CN.md#apiplayer)。

## 限制

- 支持 MP3、AAC（M4A/MP4）、Opus（Ogg 或 CAF 封装）、Vorbis、FLAC、WAV 格式的音频。
- 识别会出错，尤其是人名、背景音乐和几个人同时说话的时候。
- 跳转过去的那一段，第一句可能从半句话开始。
- 区分说话人是尽量猜：两个声音很像的人可能被当成一个人，很短的插话、几个人同时说话的地方可能不标是谁。
  每一期最多分出八个人。
- 方形、圆形是按音高猜的，不是认出了是谁。男声大声说话（演讲、舞台上）可能显示成圆形，小孩的声音也算高音。
  这个功能之前转好的单集显示菱形，点「重新转写」就有了。
